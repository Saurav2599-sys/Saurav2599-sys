### About Me

I'm a backend and data-focused software engineer who builds production systems that move and reason over data — APIs, ETL/data pipelines, cloud infrastructure, and applied ML. My background spans insurtech, proptech, and enterprise data engineering, with hands-on experience deploying machine learning models into real production APIs.

Right now I'm deliberately expanding into the applied-AI engineering stack: retrieval-augmented generation (RAG), the Model Context Protocol (MCP), agentic tool-use systems, and graph-based data modeling. The projects pinned below are that work in progress — built in public, not just claimed on a resume.

- 🔭 Currently building: a RAG-powered Q&A system, an MCP server, and an agentic automation assistant
- 🌱 Currently learning: knowledge graphs (Neo4j) and GCP-native ML deployment (Vertex AI, BigQuery, Cloud Run)
- 💼 Background: backend & integrations engineering, cloud data pipelines, ML model deployment
